# GTL2750 Control4 驱动 用户说明书

## 一、产品简介

本驱动用于将 **GTL2750 4×4 矩阵功放** 接入 Control4 智能家居系统。
驱动同时支持以下两种通信方式（可在 Composer 中切换）：

| 通信方式 | 接口 | 说明 |
| --- | --- | --- |
| 网络 (TCP) | 以太网 | 功放作为 **TCP Server**，监听端口 **8234**，由 Control4 主机主动连接 |
| 串口 (RS-232) | DB9 / 3.5 端子 | 默认 **115200 / 8N1**，可在驱动属性中切换波特率 |

驱动模型为 `audio_matrix_switch`（4 入 4 出音频矩阵），并附带场景调用、
工作模式切换、Line/Mic 切换、设备寻呼等扩展命令，可在编程中直接使用。

## 二、安装步骤

1. 将 `gtlcontrol4` 目录打包为 `.c4z`（详见《开发文档》），或直接以"目录驱动"方式
   导入 Composer。
2. 在 Composer Pro 中点击 **System Design → 添加驱动** → 选择 GTL2750。
3. 把驱动拖到对应房间。
4. **音频连接（Connections）**：
   - 把音源（如智能播放器、电视音频、AVR Pre-out）连接到 Input 1~4。
   - 把音箱区域（如客厅、餐厅）连接到 Output 1~4。
5. **控制连接**：
   - 网络模式：将驱动的 *Network* 接口与主机网卡同网段，并在属性中填入功放 IP。
   - 串口模式：将驱动的 *Serial (RS-232)* 接口绑定到 Control4 主机或 IO 扩展器的
     RS-232 端口。

## 三、属性配置

| 属性 | 说明 | 默认 |
| --- | --- | --- |
| Connection Type | 通信方式：`Network` / `Serial` | Network |
| IP Address | 功放 IP（Network 模式） | 192.168.1.100 |
| TCP Port | TCP 端口（Network 模式） | 8234 |
| Baud Rate | 串口波特率（Serial 模式） | 115200 |
| Device ID | 设备地址（十六进制 00–FF） | FF |
| Debug Mode | 调试日志：Off / Print / Log / Print and Log | Off |
| Status | 当前连接状态（只读） | Disconnected |
| Current Scene | 当前场景号（只读，自动轮询） | Unknown |
| Power | 待机状态：On / Standby | On |

> 提示：修改 Connection Type、IP、Port、波特率后驱动会自动断开并重新建立连接。

## 四、命令一览（编程可用）

下列命令在 Composer 的 **编程 → 设备特定命令** 中即可拖出。

### 1. 电源 / 待机
- **Standby On**：让功放进入待机（休眠）。
- **Standby Off**：从待机唤醒到工作状态。

### 2. 场景
- **Recall Scene (1–31)**：调用场景。**注意：协议规定场景调用间隔 ≥ 3 秒，
  驱动已自动限速，不必担心连续触发。**
- **Query Current Scene**：读取当前场景号，结果会更新到 *Current Scene* 属性，
  并触发 **Scene Changed** 事件。

### 3. 音量
- **Set Output Volume (Channel, Volume_0_1dB)**：设置输出音量。
  - Channel = 0 表示总输出；1–4 表示对应输出通道
  - Volume_0_1dB 单位 **0.1 dB**，范围：输出 -60.0 dB ~ 0.0 dB（即 -600 ~ 0）
- **Set Input Volume (Channel, Volume_0_1dB)**：设置输入音量。
  - 范围 -60.0 dB ~ +15.0 dB（即 -600 ~ 150）
- **Volume Up / Volume Down (IO, Channel, Step_0_1dB)**：以 0.1 dB 步进调节。
  - IO = Output / Input；Step 范围 1 ~ 255（即 0.1 dB ~ 25.5 dB）

### 4. 静音
- **Set Mute (IO, Channel, State)**：开关静音。
  - State = On 表示静音；Off 表示取消静音
  - Channel = 0 表示该 IO 的总通道

### 5. 矩阵路由
- **Matrix Connect (Input, Output, Connect/Disconnect)**：
  把指定输入路由到指定输出，或断开。
- 从 `audio_matrix_switch` 代理标准命令 `SET_INPUT` 也可触发路由切换，
  驱动会自动先断开该输出下的其它输入，再连接所选输入。

### 6. 工作模式
- **Set Working Mode (Group, Mode)**：
  - Group：`Channels 1 and 2` 或 `Channels 3 and 4`
  - Mode：`Stereo` / `Mono` / `Bridge` / `Matrix`

### 7. 输入灵敏度
- **Set Line Mic (Channel, Sensitivity)**：
  - Sensitivity：`0 dBu (Line)` 或 `6 dBu (Mic)`

### 8. 诊断
- **Query Device IP**：读取设备当前 IP。
- **Page Device**：让功放发出寻呼提示音，方便定位机器。
- **Send Raw Hex**：直接发送十六进制字节，用于调试或未封装的扩展指令。
  例如：`A5 C3 3C 5A FF 36 1A 00 EE`。

## 五、编程动作（Actions）

可在 Composer **编程 → Actions** 中触发：

| 动作 | 作用 |
| --- | --- |
| Reconnect | 立即断开并重连 |
| Query State | 主动读取当前场景与设备 IP |

## 六、事件（Events）

可在编程中作为触发条件：

| 事件 | 触发时机 |
| --- | --- |
| Connected | 与功放成功建立 TCP 连接，或选择串口模式时立即触发 |
| Disconnected | TCP 连接断开 |
| Scene Changed | *Current Scene* 属性发生变化 |
| Command Failed | 设备返回 `0x01` 表示写指令失败 |

## 七、典型场景配置示例

### 示例 1：晚上 22:00 进入"夜间模式"
1. 触发条件：日程 22:00。
2. 动作：
   - GTL2750 → **Recall Scene** 设为 5（事先在功放面板/配套软件中将场景 5
     保存为夜间用音量、路由）。
   - GTL2750 → **Set Output Volume** Channel=0，Volume_0_1dB=-300（即 -30 dB）。

### 示例 2：客厅电视开机后自动把电视音频路由到客厅功放输出
1. 触发条件：TV → On。
2. 动作：GTL2750 → **Matrix Connect** Input=1（电视音频输入），Output=1
   （客厅输出），Connect=Connect。

### 示例 3：晨起场景"轻音乐"
1. 触发条件：Wake-Up 闹钟。
2. 动作：
   - GTL2750 → **Standby Off**
   - 等待 1 秒（动作延迟）
   - GTL2750 → **Recall Scene** 设为 2

## 八、常见问题

**Q1：连接状态一直是 Connecting…？**
- 检查功放是否上电、网线连接是否正常；
- 在浏览器/PING 工具中确认功放 IP 可达；
- 端口默认 8234，部分批次可能改为其它端口，可在功放配套软件中确认；
- 确认未被防火墙拦截。

**Q2：命令发出后没有反应？**
- 打开驱动属性 *Debug Mode = Print*，在 Composer 的 *Lua 输出* 窗口查看
  TX/RX 报文；
- 检查 *Device ID* 是否与功放设定一致（默认 `FF` 为广播 ID，绝大多数情况下
  无需修改）；
- 若使用串口，确认波特率与功放面板一致。

**Q3：连续调场景中间有几秒等待？**
- 这是协议要求："场景调用时间间隔 ≥ 3s"。驱动内部排队限速，发完前一个场景
  会自动等 3 秒再发下一个。请勿在 Composer 中再加额外的循环。

**Q4：音量值为什么是 -600 ~ 0 这种数字？**
- 协议以 **0.1 dB** 为单位的有符号 16 位整型表达音量增益，例如 `-60` = -6.0 dB。
  驱动同时提供了从 `audio_matrix_switch` 代理 0~100 等级到 dB 的自动映射，
  用户面板调音量会被映射到 -60 dB ~ 0 dB。
