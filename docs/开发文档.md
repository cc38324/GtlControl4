## 二、代理 (Proxy) 选型

GTL2750 是 4 入 4 出矩阵功放，DSP 内部带场景、混音矩阵、Line/Mic、桥接等
功能。Control4 内置 `audio_matrix_switch` 代理对"音频矩阵"是最直接的描述，
因此我们使用：

```xml
<proxies qty="1">
  <proxy proxybindingid="5001" name="GTL2750">audio_matrix_switch</proxy>
</proxies>
```

连接 (Connections) 设计：

| ID | 类型 | 用途 |
| --- | --- | --- |
| 1000 | IP | 网络通信 (Network) |
| 2000 | RS_232 | 串口通信 |
| 101–104 | STEREO | 4 路音频输入（消费方向） |
| 201–204 | SPEAKER | 4 路音箱输出（音源方向） |
| 5001 | audio_matrix_switch | 代理本身 |

> 选 SPEAKER 类是因为 2750 是有源功放（带功率级），下游直接接被动音箱。如果
> 你要做的是**线路级矩阵**，把 201–204 改为 STEREO + audiosource=True 即可。

## 三、协议帧格式

发送帧固定 12 字节起步，可变长：

```
A5 C3 3C 5A   [ID]   [RW]   [Func]   [Len]   [Data...]   EE
| 帧头 4B   | 1B    | 1B    | 1B      | 1B     | N B       | 1B
```

- `ID`：设备地址，默认 `0xFF`（广播）。
- `RW`：`0x36` 写 / `0x63` 读。
- `Func`：功能码（见《协议命令表.md》）。
- `Len`：`Data` 字节数。
- 末尾固定 `0xEE`。

返回格式：

| 类型 | 返回 |
| --- | --- |
| 写指令成功 | `0x00` |
| 写指令失败 / 帧错误 | `0x01` |
| 读指令 | 同结构数据帧（RW = `0x63`） |

时序限制（驱动已内部限速，扩展时勿绕过）：

- 普通指令间隔 **≥ 200 ms**（驱动用 `CMD_GAP_MS = 220`）。
- 场景调用 (`0x02`) 间隔 **≥ 3 s**（驱动用 `SCENE_GAP_MS = 3100`）。

## 四、Lua 模块导览

`driver.lua` 是单文件实现。关键全局表：

| 表 | 作用 |
| --- | --- |
| `EC` | `ExecuteCommand` 处理器，键为 driver.xml 中 `<command><name>` |
| `PRP` | `OnPropertyChanged` 处理器，键为属性名 |
| `RFP` | `ReceivedFromProxy` 处理器，键为代理标准命令名 |
| `LUA_ACTION` | 编程动作处理器，键为 action 的 `ACTION` 参数值 |
| `FUNC` | 功能码常量 |

关键函数：

| 函数 | 用途 |
| --- | --- |
| `BuildFrame(rw, func, data)` | 拼装完整帧 |
| `Enqueue(rw, func, data, opts)` | 入队（`opts.scene=true` 走 3s 限速） |
| `Drain()` | 排空队列，遵守限速 |
| `HandleRx(strData)` | 接收缓冲 → `ParseOne()` 循环 |
| `OnFrame(frame)` / `OnWriteAck(code)` | 解析读响应 / 写应答 |
| `SignedVolBytes(v01dB)` | 把 0.1 dB 有符号整型编为小端 2 字节 |

时序与限速实现要点：

- 每发一条命令都更新 `g_LastSendMs`；场景命令额外更新 `g_LastSceneMs`。
- `Drain()` 起一次性定时器 `g_DrainTimer`，到点再次调用自身——避免忙等。
- 发出后 1500 ms 内没收到应答则清 `g_Pending` 继续下一条，防止单条卡死队列。

## 五、扩展：新增协议命令

下面以"读取静音状态"（假设你拿到了功能码 `0x33`）为例。

### 1) 在 `FUNC` 表加常量
```lua
FUNC.READ_MUTE = 0x33
```

### 2) 在 `EC` 加命令
```lua
EC["Query Mute"] = function(p)
    local io = IOByte(p["IO"])
    local ch = ChanByte(p["Channel"])
    Enqueue(RW_READ, FUNC.READ_MUTE, string.char(io, ch))
end
```

### 3) 在 `OnFrame()` 中分流
```lua
elseif func == FUNC.READ_MUTE and len >= 1 then
    local state = string.byte(data, 1)
    C4:UpdateProperty("Last Mute State", state == 1 and "On" or "Off")
end
```

### 4) 在 driver.xml 注册命令
```xml
<command>
  <name>Query Mute</name>
  <params>
    <param><name>IO</name>...</param>
    <param><name>Channel</name>...</param>
  </params>
</command>
```

## 六、调试

1. 把 `Debug Mode` 设为 `Print`，所有 TX/RX 报文会以 16 进制打印到 Composer
   *Lua 输出* 窗口。
2. 想看协议帧合法性，可以用 *Send Raw Hex* 命令复现协议表里的示例。
3. 网络问题：在 Composer 中执行 `LUA_ACTION → Reconnect` 强制重连。

## 七、本地打包为 .c4z

`.c4z` 实际是 zip 包。命令行：

```bash
# 在项目根目录
cd gtlcontrol4
zip -r gtl2750.c4z driver.xml driver.lua icons docs
```

Composer 加载方式两种皆可：

- **Tools → Add Driver → 选择 gtl2750.c4z**
- 或把 `gtlcontrol4` 目录直接拖到 Composer（开发模式）
