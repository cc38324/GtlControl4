# GTL2750 中控 RS232 / TCP 通讯协议命令表

> 本表整理自厂商原始协议文档。与之配套的 `驱动.lua` 中的 `FUNC` 表、`EC`、
> `RFP` 处理器均以本文为唯一事实来源。

## 一、接口参数

### 1.1 RS-232 / RS-485

| 项 | 值 |
| --- | --- |
| 波特率 | **115200** bit/s（可配：2400 / 4800 / 9600 / 19200 / 38400 / 57600 / 115200） |
| 校验位 | NONE |
| 数据位 | 8 |
| 停止位 | 1 |
| 指令发送间隔 | **> 200 ms**；场景调用 **≥ 3 s** |

### 1.2 以太网

| 项 | 值 |
| --- | --- |
| 传输协议 | TCP（设备为 **TCP Server**，由客户端发起连接） |
| 端口 | **8234** |
| 指令发送间隔 | **> 200 ms** |

## 二、协议帧格式

### 2.1 发送帧结构（最少 9 字节）

| 位置 | 字节 | 说明 | 取值 |
| --- | --- | --- | --- |
| 1–4 | 帧头 | 固定 | `A5 C3 3C 5A` |
| 5 | ID | 设备 ID（默认 `0xFF`） | `0x00–0xFF` |
| 6 | 读写位 | 写=`0x36`，读=`0x63` | `0x36 / 0x63` |
| 7 | 功能码 | 见 §三 | `0x00–0xFF` |
| 8 | 数据长度 | 数据字节数量 | `0x00–0xFF` |
| 9 … N | 数据 | 见各功能码说明 | — |
| 末位 | 帧尾 | 固定 | `0xEE` |

### 2.2 返回说明

| 类型 | 返回 |
| --- | --- |
| 写指令 → 应答字节 | `0x00` = 成功 / `0x01` = 失败 |
| 读指令 → 同结构数据帧 | 读写位 = `0x63` |
| 格式错误 | `0x01` |

## 三、功能码

### 3.1 场景调用（写，功能码 `0x02`）

`A5 C3 3C 5A FF 36 02 01 [场景号] EE`

- 场景号：`0x01–0x1F`（1–31）。场景 1 为出厂默认。
- 示例：`A5 C3 3C 5A FF 36 02 01 01 EE` → 调用场景 1

### 3.2 场景读取（读，功能码 `0x02`）

`A5 C3 3C 5A FF 63 02 00 EE`
- 返回：`A5 C3 3C 5A FF 63 02 01 [当前场景号] EE`

### 3.3 静音控制（写，功能码 `0x03`）

`A5 C3 3C 5A FF 36 03 03 [I/O] [通道] [静音] EE`

| 字段 | 取值 |
| --- | --- |
| I/O | `0x01` = 输入 / `0x02` = 输出 |
| 通道 | `0x01–0x04`（`0x00` = 总） |
| 静音 | `0x00` = 取消 / `0x01` = 静音 |

示例：
- `…03 03 01 01 01 EE` → 输入通道 1 静音
- `…03 03 02 00 01 EE` → 输出总音量静音

### 3.4 音量增益设置（写，功能码 `0x04`）

`A5 C3 3C 5A FF 36 04 04 [I/O] [通道] [低字节] [高字节] EE`

- 音量 = 低/高字节组成 **16 位有符号整型**，单位 **0.1 dB**。
- 范围：输入 **-60.0 dB ~ +15.0 dB**；输出总 **-60 dB ~ 0 dB**。
- 字节序：**低字节在前，高字节在后**（小端）。

示例：
- `…04 04 01 01 32 00 EE` → 输入通道 1 = +5.0 dB（`0x0032` = 50）
- `…04 04 02 00 C4 FF EE` → 输出总音量 = -6.0 dB（`0xFFC4` = -60）

### 3.5 音量增益递增 / 递减（写，功能码 `0x05`）

`A5 C3 3C 5A FF 36 05 04 [I/O] [通道] [+/-] [增减值] EE`

- `+/-`：`0x00` = 加 / `0x01` = 减
- 增减值步进 **0.1 dB**：`0x01` = 0.1 dB；`0xFF` = 25.5 dB

### 3.6 Line / Mic 切换（写，功能码 `0x06`）

`A5 C3 3C 5A FF 36 06 03 [通道] 00 [灵敏度] EE`

- 灵敏度：`0x00` = 0 dBu（Line） / `0x01` = 6 dBu（Mic）

### 3.7 矩阵混音（写，功能码 `0x09`）

`A5 C3 3C 5A FF 36 09 03 [输入通道] [输出通道] [接通] EE`

- 接通：`0x01` = 接通 / `0x00` = 断开
- 通道：`0x01–0x04`

### 3.8 工作模式设置（写，功能码 `0x16`）

`A5 C3 3C 5A FF 36 16 02 [通道组] [工作模式] EE`

| 字段 | 取值 |
| --- | --- |
| 通道组 | `0x00` = 通道 1 & 2；`0x01` = 通道 3 & 4 |
| 工作模式 | `0x00` 立体声 / `0x01` 单声道 / `0x02` 桥接 / `0x03` 矩阵 |

### 3.9 待机开关（写，功能码 `0x17`）

`A5 C3 3C 5A FF 36 17 01 [开关] EE`

- `0x00` = 待机打开（休眠）
- `0x01` = 待机关闭（工作）

### 3.10 设备 IP 读取（读，功能码 `0x18`）

`A5 C3 3C 5A FF 63 18 00 EE`

- 返回示例：`A5 C3 3C 5A FF 63 18 04 C0 A8 08 4A EE` → IP = `192.168.8.74`

### 3.11 设备呼叫（写，功能码 `0x1A`）

`A5 C3 3C 5A FF 36 1A 00 EE`

让设备发出"呼叫"提示音，用于物理定位。

## 五、音量编解码参考

设备音量字段是 **16 位有符号整型，0.1 dB 步进，小端字节序**。

| dB 值 | 整型值 | 16 位补码 | 字节（低，高） |
| --- | ---: | --- | --- |
| +5.0 dB | 50 | `0x0032` | `32 00` |
| 0 dB | 0 | `0x0000` | `00 00` |
| -6.0 dB | -60 | `0xFFC4` | `C4 FF` |
| -25.5 dB | -255 | `0xFF01` | `01 FF` |
| -60.0 dB | -600 | `0xFDA8` | `A8 FD` |

Lua 编码示例（节选自 `driver.lua`）：

```lua
function SignedVolBytes(v01dB)
    local v = tonumber(v01dB) or 0
    if v < 0 then v = v + 0x10000 end          -- 16-bit two's complement
    return string.char(v % 256, math.floor(v / 256) % 256)
end
```

## 六、补充说明：VOD / APP 协议

厂商另有一份 **VOD / APP 通讯协议**（蓝牙 3.3 V 接口，引导码 `FF FE FD FC FB FA`
或 `…F9`），用于配套 APP 直接控制 AVK 系列、H6、AVK1200 等机型。该协议
与本驱动使用的 RS232 / TCP 协议**不兼容**，因此当前驱动**不实现**它；如需
通过蓝牙网关接入，请单独写蓝牙桥接驱动。
